# Technique selection guide (task × stage → technique)

The coach's prescription table. **Diagnose before prescribing** — always establish:
1. **Task type** — what must the knowledge/skill do? (exact recall, conceptual
   understanding, procedural execution, complex skill, judgment)
2. **Learning stage** — first exposure / building understanding / consolidation /
   exam-or-performance prep / maintenance; for skills, the RAIL stage.
3. **The current system** — what are they doing now, and what's the biggest constraint?
   (Often the answer is deleting a passive method, not adding a new one.)

## By task type

| Task | Right tools | Wrong tools (common mistake) |
|---|---|---|
| Exact discrete facts, terminology, vocab | Flashcards/SRS *after* encoding filters the residue; memory palace/link method; swap cues regularly | Flashcards as the whole system; carding before encoding |
| Conceptual topic (theories, systems, relationships) | Priming → PACER reading → mind mapping (GRINDE) → analogies + critique → free-recall testing | Rereading, highlighting, linear wordy notes, 1:1 flashcards |
| Procedural problem-solving (math, physics, coding) | Worked examples (novice) → faded completion → practice problems; test declarative side too | Practice problems from zero (noise); worked examples forever (recognition, not generation) |
| Deep understanding of a topic you "sort of" know | Teach-back (this app's Aria mode); closed-book summarization; analogy critique | More input (videos, rereading) |
| Reading a paper/textbook/documentation | Priming, PACER, deep processing loop; ladder method if dense or you're tired | Cover-to-cover consumption, notes-as-transcript |
| Exam preparation | Retrieval at the examined Bloom's level; weekly/monthly self-tests; peer testing; past-paper style free recall | Night-before practice papers; recognition review; drilling only what feels good |
| Complex skill (instrument, sport, speaking, learning-to-learn itself) | RAIL stage diagnosis → stage-matched actions; 1–2 new elements at a time; ~1:5 theory:practice; varied practice at iteration stage | Bingeing theory (theory overload); chasing speed before consistency |
| Professional domain knowledge | Learning sprints (explicit goals → aggressive consumption → extended application); tactical studying; delete the latent learning period | Passively completing courses; six weeks of learning before first feedback |

## By learning stage

- **First exposure:** priming/scoping (big picture first, always), ladder method rung 1,
  worked examples (procedural), thinner layers if overwhelmed. Goal: schema, not detail.
- **Building understanding:** deep processing loop on everything, mind mapping (GRINDE),
  delayed note-taking, analogies + critique, application questions. Goal: organized
  network.
- **Consolidation:** teach-back, closed-book summarization, merging/upgrading
  flashcards, synthesis essays as revision. Goal: fluent, restructured, own words.
- **Exam / performance prep:** free recall at target level, peer testing, timed varied
  practice, gap-list triage. Goal: no surprises.
- **Maintenance:** spaced retrieval at low frequency (strong encoding tolerates weeks),
  real use of the skill (avoid skill decay).

## Stage transitions the coach should watch for

- Worked examples feel obvious → switch to practice problems (expertise reversal).
- Flashcard answered before finishing the question → swap the cue or merge the card up.
- Mapping feels smooth and fast → raise to level-3 quality: alternatives + emphasis.
- Learner reports comfort/boredom with any technique → the technique's job at this
  stage is done or the level is too low; increase difficulty or move stage.
- Guided prompts (from this app's learner mode) feeling redundant → reduce scaffolding;
  the loop should be internalizing.

## Universal prescriptions (safe defaults)

Whatever the task: prime before consuming; run the deep processing loop; keep
consumption ≤ digestion; test early at the target level; treat "silly mistakes" as
gaps; change 1–2 habits at a time and log the experiments.

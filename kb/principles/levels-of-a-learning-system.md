# Levels of a learning system (principles → thinking moves → strategies → tools)

Learning advice gets muddled when four different levels are treated as one. The coach
should always know which level it's talking about — and correct learners who confuse
them ("is pause–simplify–compare–connect–judge a strategy?" — it's both a thinking
habit and, packaged into a sequence, a strategy).

## Level 1 — Principles

Truths that guide decisions; not things you "do":
learning = encoding + retrieval + enablers; encoding determines storage quality;
retrieval finds gaps and strengthens memory; understanding lives in relationships and
context; practice must match how the knowledge will be used; reflection improves the
process itself.

## Level 2 — Thinking moves

The mental actions used *while* learning — pause, simplify, compare, connect, judge
importance, ask why it matters / what it depends on / what it affects / what
prerequisite is missing, create an example, create an analogy, predict before checking.

These run **constantly but selectively**: not every sentence needs deep processing.
Deploy them when an idea is important, confusing, likely to be tested, connects to many
things — or when you catch yourself reading passively. They are the default habits of a
strong encoder, not optional hacks, and they are NOT what goes in a learning log.

## Level 3 — Strategies

A **planned sequence of actions for a learning goal** — this is the level the coach
prescribes and the learning log records:

- **Concept encoding**: chunk → pause → simplify in own words → compare → connect to
  the bigger picture → judge why it matters → tiny diagram/explanation.
- **Brain dump retrieval**: close notes → write everything → organize roughly → check
  source → mark missing/wrong/shallow → restudy only the gaps. (Theory-heavy subjects.)
- **Flashcards**: only genuinely recall-worthy facts; simple cards; spaced; a
  repeatedly-failing card means stop repeating and re-encode deeper.
- **Worked example → closed-book practice**: study one example, explain each step,
  cover it, recreate from memory, then similar → varied problems. (Math, coding,
  physics.)
- **Error log**: record each error, label its type (forgot fact / misunderstood /
  careless / wrong method / weak prerequisite / time pressure / misread), find the
  cause, build a targeted drill, retest later.
- **Teach-back**: explain aloud without notes → notice where it breaks → check →
  re-explain simpler with an example and a comparison. (This app's Aria mode.)
- **Mind map / schema building** (GRINDE): group, relate, reorganize until the
  structure makes sense.
- **Past-paper / output-aligned practice**: exam-style question under real conditions →
  mark → identify the missing knowledge/skill → study that gap → next question. One of
  the most important strategies because it aligns study with the final output.
- **Project/application**: learn a small piece of theory → apply immediately in a tiny
  real example → get stuck → check → fix → repeat. (Practical skills.)

## Level 4 — Tools

Anki, Notion, Obsidian, paper, whiteboard, AI, textbooks, past papers. **Tools are not
strategies.** "Using Anki" is not a strategy; "Anki for high-value factual recall after
encoding the concept properly" is. "Using AI" is not a strategy; "AI quizzes me after I
write my own explanation" is.

## Coaching cues

- Learner asks "should I use Anki/Notion/AI?" → wrong level; what's the goal and the
  gap, then which strategy, then which tool serves it.
- Learner treats thinking moves as occasional tricks → promote them to default habits.
- Learner logs thinking moves or files tools as achievements → point at the right level.

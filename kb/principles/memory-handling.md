# Memory handling (how memory actually works)

"Poor memory" is almost always poor memory *handling*. Research shows most people have
very similar raw memory capacity; memory champions and people with "naturally great"
memories are using strategies — trained or instinctive. Memory outcomes are decided by
what you *do* with information, which is controllable and trainable, not by fixed
capacity.

## The model

- **Short-term / working memory lasts about 15–30 seconds.** Forgetting what you read
  two minutes ago is not a short-term memory failure — two minutes is already long-term
  memory territory. What feels like "bad short-term memory" is rapid decay of poorly
  encoded long-term memory.
- **The 15–30 second window is the whole game.** What you do with information during
  that window — while it sits on the working-memory "workbench" — dictates whether it
  passes into long-term memory as something meaningful or lands in the forget pile.
  Passive processes (rereading, repetition, merely intending to understand) barely
  transform the information, so it decays fast.
- **Working memory has a "weight limit,"** not just a 5–9 item limit. One conceptually
  dense term you keep having to re-define is a single heavy item; nine digits in an
  obvious pattern are nearly weightless. Familiarity and chunking (e.g. "serotonin
  syndrome" is one item to a medic, two words to anyone else) change the load. Exceeding
  the limit causes cognitive overload, and an overloaded brain produces no useful output.

## The six strategies

1. **Increase complexity of processing.** Actively transform the information instead of
   passively re-consuming it: extract the key concepts, re-explain them in simpler and
   more intuitive words, create analogies, connect to prior knowledge, evaluate how
   important each piece is for your purpose, ask what problems it could solve, read as if
   you'll teach it. More manipulation = more meaning = better storage.
2. **Handle it immediately.** "Consume everything first, make sense of it later" is a
   trap: unhandled information is forgotten, so the later "review" is really relearning
   from scratch. Spending ~10 extra seconds handling information the moment it arrives
   saves the time you'd waste relearning it.
3. **Pause for handling.** Don't keep reading/watching while still processing the last
   piece — new input pushes working memory into overload. Stop the video, stop reading,
   finish making meaning, then let the next piece in. This stop-start rhythm massively
   raises quality-memory-per-minute. (This is the "pause" in the pause–simplify–compare–
   connect–judge loop; see the active-reading technique doc.)
4. **Avoid distracting noise.** Speech and sounds occupy working-memory space even when
   ignored. Don't try to concentrate through it — block it (noise-cancelling headphones)
   or move.
5. **Practice retrieval — with the right cues.** Failure to recall is often retrieval
   failure, not storage failure. Practice using the knowledge at the fluency level you
   actually need; retrieval attempts expose gaps and give working memory a chance to
   correct and re-encode. Crucially, match the retrieval cue to real usage: if you'll
   need the knowledge for complex questions, teaching, or problem-solving, flashcard-style
   cues won't transfer well — that cue mismatch is one of the biggest limitations of
   flashcards.
6. **Think on paper (cognitive offload).** Map concepts and their connections on paper,
   then clean the map up. The paper holds what working memory can't, so working memory
   stays focused on one connection at a time ("how does short-term memory relate to
   long-term memory?") while the growing understanding accumulates externally. This is
   the highest-leverage use of note-taking.

## Coaching cues

- "I read for two hours and remember nothing days later" → strategies 2 and 3: they
  consumed without handling; introduce pause-and-process.
- "I have a bad memory" → reframe to memory handling; capacity is not the problem.
- "I know it with flashcards but blank in the exam/discussion" → strategy 5: cue
  mismatch; practice retrieval in the target format.
- "It's too much to hold in my head" → strategy 6: think on paper, offload.
